یک ربات هوش مصنوعی پیشرفته تلگرام با قابلیت‌های متنوع، ساخته شده بر روی **Cloudflare Workers** و **D1 Database**.

---

## ✨ قابلیت‌ها

### 🤖 هوش مصنوعی
- 💬 **چت هوشمند** با ۱۱ موتور AI مختلف (Gemini, GPT-4o, Claude, DeepSeek, ...)
- 🎨 **تولید تصویر** با DALL-E 3, Midjourney, Flux
- 🎬 **تولید ویدیو** با Runway, Kling, Sora
- 🎵 **تبدیل متن به صدا** با ElevenLabs, OpenAI TTS
- 📝 **خلاصه‌سازی** متون طولانی
- 🌐 **ترجمه** به بیش از ۱۰۰ زبان
- 💻 **تولید کد** در زبان‌های مختلف

### 💰 سیستم مالی
- 📊 **کیف پول** با اعتبار جداگانه برای هر سرویس (متن، تصویر، صدا، ویدیو)
- ⭐ **اشتراک ویژه** با دسترسی نامحدود
- 👥 **سیستم دعوت** با پاداش
- 💳 **پرداخت آنلاین** (زرین‌پال، زیبال، کارت به کارت، کریپتو)

### 👑 مدیریت
- 📊 **پنل ادمین** کامل
- 📢 **پیام همگانی** به همه کاربران
- 🚫 **مدیریت کاربران** (بن/آنبن، VIP، محدودیت)
- 📝 **سیستم تیکت** پشتیبانی
- 📈 **آمار و گزارش‌گیری** پیشرفته

### 🎭 شخصیت‌ها
- 👑 **۱۳۶ شخصیت** حرفه‌ای در ۱۵ دسته‌بندی مختلف
- 🎯 **رهبری و مدیریت**، 🧠 **روان‌شناسی**، ⚙️ **فنی**، 🎨 **خلاقیت**، 😂 **سرگرمی**، 📚 **آموزشی**، 🏥 **سلامتی**، 🤝 **مذاکره**، 💰 **مالی**، 🌱 **کوچینگ**، 🏗️ **مهندسی**

### 🔒 امنیت
- ✅ احراز هویت کاربران
- 🛡️ محدودیت نرخ درخواست
- 🔐 ذخیره‌سازی امن کلیدهای API
- 📊 لاگ‌گیری کامل فعالیت‌ها
